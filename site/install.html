推荐
  1. 1
    下载 FC Supporter

    获取扩展安装包并解压到本机。

    ↓ 下载扩展 ZIP当前版本 1.0.0 · 仅提供源码包，首次安装需手动加载
  2. 2
    在浏览器中打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions；Edge 用户输入 edge://extensions。

  3. 3
    开启开发者模式并加载扩展

    开启右上角的“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的文件夹。

  4. 4
    打开 FC Supporter 并导入球员表

    点击浏览器工具栏里的扩展图标，在“球员数据”页导入 CSV 或 JSON。

安装与使用说明

本地加载扩展⌄

目前通过 ZIP 下载源码包并在浏览器中“加载已解压的扩展程序”安装。无需登录 FC Supporter 账号。

如需升级，下载新版本后，在扩展管理页移除旧版，再加载新文件夹。导出的球员 JSON 可用于备份和迁移数据。

再次下载扩展 ZIP →
导入球员数据⌄

球员页面支持 CSV 和 JSON。CSV 模板包含名称、评分、位置、俱乐部、联赛、国家、价格、自有标记和基础属性。市场数据需由你手动整理导入。

化学反应与球队评分是本地估算；特殊卡加成和游戏内实时价格可能需要自行核对。

浏览器与平台⌄

本版本提供 Chrome 和 Edge 的 Manifest V3 安装包。手机浏览器及 Firefox 暂未提供单独安装包。

✓

本地运行，数据留在你的浏览器

扩展不连接 EA、不读取 EA 登录状态、不访问俱乐部或转会市场，也不会自动买球员或提交 SBC。球员数据仅保存在浏览器本地存储中。

FC Supporter 是独立的社区工具，与 Electronic Arts 或 fodder.gg 无关。EA 建议避免第三方浏览器扩展，并禁止自动买家和机器人。请查看 EA SPORTS FC 规则。阵容估算仅供规划参考。
