Chrome / Edge 扩展

推荐
  1. 1
    下载 FC Supporter

    获取扩展安装包并解压到本机。

    ↓ 下载扩展 ZIP当前版本 1.0.0 · 仅提供源码包，首次安装需手动加载
  2. 2
    在浏览器中打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions；Edge 用户输入 edge://extensions。

  3. 3
    开启开发者模式并加载扩展

    开启右上角的“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的文件夹。

  4. 4
    打开 FC Supporter 并导入球员表

    点击浏览器工具栏里的扩展图标，在“球员数据”页导入 CSV 或 JSON。

其他安装方式

Chrome / Edge 上的用户脚本⌄
  1. FC Supporter 目前没有 Tampermonkey 用户脚本版本，因此不需要安装脚本管理器。
  2. 直接打开 网页工具 即可使用；球员数据保存在当前浏览器中。
  3. 如果希望从浏览器工具栏打开，请按上方步骤安装 Chrome / Edge 扩展。
Firefox⌄
  1. 在 Firefox 中打开 FC Supporter 网页工具。
  2. 在“球员数据”页导入 CSV 或 JSON，工具会在 Firefox 本地保存数据。
  3. 目前没有单独的 Firefox 扩展包；网页工具无需安装即可使用。
iOS / Safari⌄
  1. 在 iPhone 或 iPad 上用 Safari 打开 FC Supporter 网页工具。
  2. 点“分享”按钮，选择“添加到主屏幕”，以后可从主屏幕快捷打开。
  3. 首次使用时导入 CSV 或 JSON。当前没有 iOS 原生应用或 Safari 扩展。

添加到主屏幕是网页快捷方式，不是独立 App。

安卓⌄
  1. 在 Android 手机上用 Chrome 或 Firefox 打开 FC Supporter 网页工具。
  2. 如需放到桌面，在浏览器菜单中选择“添加到主屏幕”或“安装应用”（若浏览器显示该选项）。
  3. 打开网页并导入 CSV 或 JSON。当前没有 Android APK 或独立浏览器扩展包。

桌面图标会打开网页工具；数据保存在所用浏览器中。

✓

本地运行，数据留在你的浏览器

扩展不连接 EA、不读取 EA 登录状态、不访问俱乐部或转会市场，也不会自动买球员或提交 SBC。球员数据仅保存在浏览器本地存储中。

FC Supporter 是独立的社区工具，与 Electronic Arts 或 fodder.gg 无关。EA 建议避免第三方浏览器扩展，并禁止自动买家和机器人。请查看 EA SPORTS FC 规则。阵容估算仅供规划参考。
