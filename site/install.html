安装 FCSupporter

Chrome / Edge 扩展

  1. 1
    获取 FC Supporter 扩展安装包，并解压到本机。
    下载 Chrome 扩展
  2. 2
    在扩展管理页开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的文件夹。
  3. 3
    点击浏览器工具栏里的 FC Supporter，选择“打开 EA FC 增强面板”；也可打开离线规划工具。

1.2.0 测试版 · 含恢复的 EA 客户端 1.3.9 · 尚未上架应用商店

其他安装方式

Chrome / Edge 上的用户脚本
  1. 1
    从浏览器的扩展商店安装 Tampermonkey。
  2. 2
    在 chrome://extensions 或 edge://extensions 中打开 Tampermonkey 的详情，并启用“允许用户脚本”。旧版本可启用“开发者模式”。
  3. 3
    安装 FC Supporter 用户脚本，并在 Tampermonkey 中确认安装。
    安装 FC Supporter
  4. 4
    打开 EA FC 网页版，点击页面右下角的 FC Supporter，进入阵容规划工具。
Firefox
  1. 1
    从 Firefox 附加组件商店安装 Tampermonkey。
  2. 2
    点击下方按钮，在脚本管理器中确认安装。
    安装 FC Supporter
  3. 3
    打开 EA FC 网页版，点击 FC Supporter 入口。也可直接打开 网页工具。
iOS / Safari
  1. 1
    在 iPhone 或 iPad 上安装 Userscripts，并打开一次。
  2. 2
    在“设置 → Safari → 扩展”中启用 Userscripts，并允许它在 EA 网页上运行。
  3. 3
    用 Safari 打开用户脚本，点地址栏的扩展菜单，选择 Userscripts，再确认安装。
    安装 FC Supporter
  4. 4
    回到 EA FC 网页版并刷新，点击 FC Supporter 入口。
安卓
  1. 1
    使用支持扩展的 Firefox，安装 Tampermonkey。
  2. 2
    在 Firefox 中安装用户脚本并确认。
    安装 FC Supporter
  3. 3
    打开 EA FC 网页版，必要时在浏览器菜单启用“桌面版网站”，点击 FC Supporter 入口。

Chrome 扩展已接入恢复的原 EA 页面客户端，连接原服务并保留原账号和 Gold 权限；真实 EA 功能待验收。其他平台用户脚本目前提供离线规划入口。

开始使用

  1. 安装扩展后可选择“打开 EA FC 增强面板”，登录 EA 并启用恢复的原客户端。原账号和 Gold 权限由原服务处理。
  2. 使用离线模式时，直接打开网页工具或扩展内的离线规划工具。
  3. 在“球员数据”中导入 CSV / JSON，也可以先载入演示名单。
  4. 设置 SBC 要求、阵型和预算，生成阵容规划。
  5. 导出名单备份。网页版和扩展版的数据分别保存在各自浏览器空间中。

隐私说明

离线规划工具将导入的球员数据保存在当前浏览器的本地存储中，不上传名单。

启用 EA 增强模式后，恢复的原客户端会读取 EA 页面中的功能数据，并向 fodder.gg 与 solve.fodder.gg 发送功能所需请求。其账号登录、Gold 权限和服务端数据处理仍由原服务提供；本项目未独立重建这些服务。

用户脚本仅添加工具入口。点击入口会打开本项目网页，不读取 EA 页面中的账号或俱乐部数据。

你可以在“球员数据”页导出备份或清空数据。清除浏览器站点数据也会删除本地名单。
